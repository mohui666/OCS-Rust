# 桌面使用指南

## 安装与首次启动

当前 Release 提供 Windows x64 安装程序和 macOS Apple Silicon（arm64）桌面包。Windows 运行 `OCS-Rust-Desktop-0.1.1-windows-x64-setup.exe`；macOS 解压 ZIP，将 `OCS Rust.app` 拖入「应用程序」。包内包含运行所需的 Node 与 Playwright 适配器，不要求使用者另外安装 Node；Chromium 和扩展由「工具 → 初始化设置」准备，不在桌面包中。

启动时不再自动显示旧公告、教程和初始化窗口。首次使用请手动打开初始化设置，完成后创建浏览器。

此版本使用 ad-hoc 签名，没有 Apple 公证。macOS 可能显示来源提示，由使用者决定是否通过系统「隐私与安全性」允许打开。首次访问配置加密密钥时，也可能出现钥匙串窗口；密码只在 macOS 系统窗口输入。更新后的本地签名身份变化可能再次触发钥匙串授权。

应用与旧版 `OCS Desktop` 分开存放数据。macOS 默认目录为 `~/Library/Application Support/local.ocs.rust`；Windows 默认为 `%APPDATA%\local.ocs.rust`，程序安装在 `%LOCALAPPDATA%\OCS Rust`。正常退出应用会关闭其管理的浏览器和本次题库服务。

## 浏览器和脚本

1. 使用初始化向导下载兼容的 Chromium，或选择已有的兼容浏览器路径。
2. 创建或选择一个浏览器，启动后确认脚本管理扩展已安装。
3. 安装 Release 的 `ocs-rust.user.js`，或使用桌面提供的内置脚本。详见[脚本安装说明](userscript.md)。
4. 登录课程平台，手动选择课程。打开课程页后，脚本面板会显示版本。

「恢复登录和上次页面」默认开启，使用同一浏览器资料目录保存 Cookie 和标签页。需要通过正常退出让浏览器写盘；站点注销或会话失效后仍需重新登录。当前版本没有无头浏览器或无窗口 OCS 启动方式。

## AI 配置

入口为 **脚本 ⚙️ 全局设置 → AI / 其他题库设置**。桌面顶部「AI 题库」使用同一套表单。

### GPT 登录态

- 使用本机已有的 Codex CLI 和登录目录，不需要填写 API Key。
- 自动查找有效路径；未识别时，在桌面面板的「高级设置」中使用「自动配置路径」或手动填写。
- 模型列表来自本机 `models_cache.json`。列表可能过期，也可以直接填写准确的模型 ID；是否可用取决于当前账户和 CLI。
- 选择模型与推理强度后点击「保存设置」。路径识别不会替用户登录，也不通过调用模型验证账户。

### API Key

1. 选择「API Key」，输入服务商的 API 地址和密钥。支持兼容的 `/chat/completions` 与 `/responses` 协议。
2. 点击「获取模型」，或手动输入模型 ID。基础地址可包含 `/v1`，也可直接使用完整接口地址。
3. 按服务商要求设置推理强度、协议、答案格式、温度和输出长度。无需覆盖的可选参数保持默认。
4. 点击「保存设置」。地址变更后须重新填写对应密钥；密钥留空保留原值，也可在高级设置中显式删除。

答案格式有 JSON Object、严格 JSON Schema 和仅提示词约束。并非所有服务商支持全部参数；严格格式不受支持时使用仅提示词约束。模型查询只请求模型列表，不产生答题请求。

### 何时调用 AI

题库服务随 OCS 默认就绪，首次注册时不替用户打开「使用 AI 答题」，之后保留选择。只有开关启用且脚本实际搜题时才发送题目。打开软件、选择模型、保存参数或勾选开关本身均不调用答题。

取消选择后不再接受新的 AI 搜题请求，已经执行的请求不会被强行中断。API 模式发送题干和选项到所填服务商，不含联网搜索工具；费用和额度由服务商账户决定。GPT 模式则沿用现有 Codex 账户。

API Key 使用系统钥匙串保护的密钥加密保存在本机。课程弹窗内的表单由本地服务提供，密钥不写入用户脚本或题库订阅配置。不要把真实配置、登录目录或 Cookie 提交到仓库或公开 Issue。

## 其他题库与填答速度

「其他题库」页签只显示非 AI 题库。需要时展开「添加 / 编辑其他题库」，粘贴服务商提供的配置或订阅链接并保存。多个配置用 `###` 分隔。AI 的内部模板由桌面维护，无需手工编辑。

「本地缓存快速填答」默认开启；在适用的超星整页场景中，已缓存答案默认每批填写 16 题，范围为 1～32。它减少已有答案后的逐题等待，不会加快模型生成本身。「并行页面数」控制 AI 请求并发，与每批填题数不同。

进度中的「已填入」表示脚本完成匹配与填写，不代表网站已经保存、提交或评分。「答题完成后」行为由自己的脚本设置决定，首次使用应检查该选项。

## 旧资料迁移与备份

- 先关闭旧版管理的浏览器。
- 在「工具 → 迁移旧版资料（复制）」选择旧数据目录的 `config.json`。该操作复制资料与扩展，不改写旧目录。
- 普通「导入数据」只导入配置，不复制浏览器登录资料。
- 新版导出使用密码保护；在另一台机器导入时使用该密码。本机配置加密依赖系统钥匙串，直接搬运加密文件不等于跨机器迁移完成。

迁移成功后仍需检查网站登录是否有效。旧版由原系统加密的配置可能必须在原机器导出后再迁移。

## 更新与卸载

更新桌面前正常退出 OCS；Windows 运行新版安装程序，macOS 用新包替换应用。数据目录保持独立。脚本可以单独更新，更新后重新加载已打开的课程页面。上游 Electron 安装包不能用于更新本分支。

卸载应用不会主动删除数据目录。如需清除浏览器资料和配置，应先自行备份，再通过系统文件管理器处理对应数据目录；钥匙串条目名为 `local.ocs.rust`。

## 常见问题

- **模型不在列表中**：GPT 模式读取的是本机缓存；API 模式取决于服务商的模型列表接口。支持直接输入准确 ID，列表存在也不保证账户有调用权限。
- **设置入口仍是旧版**：确认脚本管理器安装了本仓库版本，并重新加载课程页；不要同时启用多份 OCS 脚本。
- **AI 表单提示没有连接桌面**：使用 OCS Rust 启动的浏览器并保持桌面运行。独立普通浏览器中的脚本不具备桌面注入的连接信息。
- **长时间等待**：超时 `0` 表示无限等待。查看处理中数量和错误；这不是模型进度百分比。
- **更新后又要求系统密码**：ad-hoc 签名随构建内容变化，系统可能再次确认钥匙串访问；此版本未使用稳定的 Developer ID 签名。
