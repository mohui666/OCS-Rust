# 0.1.0 验证范围

记录日期：2026-10-04。公开摘要只描述已观察到的结果与适用范围，不附带本机配置、私人路径、登录资料或课程截图。

## 本次发布

发布组合为桌面 `0.1.0` + 用户脚本 `0.1.0`。功能来自前一开发版本；本次整理文档、规范版本、补齐许可和分包，并对发布源码重新构建和检查。

- 运行范围：macOS Apple Silicon（arm64）。桌面、前端和脚本按该平台打包。
- 检查范围：脚本语法、Vue 类型、Rust 编译、正式打包、macOS 签名完整性、包内资源与分包哈希。
- 按本次交付约束，不运行新的自动化测试、真实 API 答题或课程提交。
- Release 文件清单记录该发布提交、构建目标和 SHA-256；下载校验通过只证明文件一致，不证明功能全部可用。

## 已完成的界面核对

同日对版本规范前、功能相同的开发包实际打开过桌面和课程浏览器：

- ScriptCat 安装成功，课程页面显示新版脚本。
- 脚本内同一弹窗显示 GPT 登录态、模型选择、推理强度、API 地址 / 密钥和模型获取入口。
- 本机模型缓存能显示列表；这不证明所有列出的模型均有调用权限。
- 「其他题库」编辑区不再包含 AI 内部 JSON。
- 六个本地平台图标正常显示，导航中只保留「网课网站」分组。
- 打开及切换配置页面期间观察到的 AI 解答数为 0。

这些界面观察不是新版本号发行包的完整回归，也没有验证真实 AI 答题准确率。

## 历史实现检查

Rust 迁移阶段曾通过配置加密互通、资料复制、请求去重与缓存、HTTP 访问控制、工作进程退出等定向检查。406 组数据是原 Python 实现的对照样本数量，不是模型调用数量。

快速填答与进度阶段使用 Chromium 合成题目、模拟题库和虚拟时钟验证过 16 / 32 题调度、暂停 / 继续 / 停止及迟到响应处理。其调度耗时不能当作真实课程上的速度倍数，也不代表平台成功提交。

以上是历史证据，不冒充本次重新运行的结果。对应测试源码随仓库公开，使用者可自行复现。

## 未验证或不提供

- Windows、Linux、Intel Mac 构建及实机功能。
- 全部课程平台、真实 AI 答案质量和课程保存 / 提交 / 评分。
- macOS 录屏采集的完整实机画面。
- Apple Developer ID 签名、公证和自动更新服务。
- 本地模型部署或 OCR 模型；验证码保留人工处理。
