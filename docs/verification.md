# 0.1.1 验证范围

记录日期：2026-10-08。发行组合为桌面 `0.1.1` + 用户脚本 `0.1.1`。本文只记录本次观察到的结果；不公开本机配置、账户资料或课程截图。

## 原生构建与自动化检查

| 平台 | 原生构建 | 本次通过的 Rust 测试 |
| --- | --- | --- |
| Windows 11 x64 | Rust 1.97.1、Node 22.19.0；NSIS 安装包 | 6 个单元测试 + 18 个契约测试 |
| macOS 27.0.1 arm64 | Rust 1.99.0、Node 24.19.0；`.app` | 7 个单元测试 + 22 个契约测试 |

两端均执行设置模块冒烟、Vue 类型检查、Vite 构建和 Rust release 构建。平台条件编译导致测试数量不同。macOS 应用另通过 ad-hoc 签名完整性检查。

定向检查覆盖：新配置与已保存空脚本列表初始化、本地 `.user.js` 安装路由、鉴权和文件注册约束、旧数据迁移及路径变化、请求去重与缓存、HTTP 请求尺寸边界，以及超大请求和停滞上传。超大请求检查验证完整错误响应，不代表题目已成功解答。

用户脚本通过语法检查及设置模块加载；即使保留旧版自动通知配置，更新模块完成回调也不再安排自动公告。

## 运行检查

macOS 原生浏览器适配器使用 Chrome for Testing 137 完成 6 项检查：启动、书签页、页面监控识别、监控清理、聚焦和关闭。桌面首页及 AI 配置窗口实际打开；观察期间 AI 解答数保持 0。

Windows 最终 NSIS 安装包已覆盖安装并实际启动，系统登记版本为 `0.1.1`。在独立全新配置中点击「一键修复」，确认选择兼容浏览器、安装 ScriptCat 1.1.2（MV3）和随附脚本 0.1.1，修复完成后警告消失。随后通过界面创建浏览器并启动、聚焦、关闭，未留下待确认的脚本安装页，未观察到页面异常。另在实际 ScriptCat 管理页面确认脚本 0.1.1 已注册且启用；重启桌面后浏览器配置和脚本仍保留，启动弹窗数量为 0。

Windows 安装版的本地题库接口分别用空请求、262145 字节和 4 MiB 请求验证完整 HTTP 413 JSON；262144 字节边界请求进入 JSON 校验并返回 400。模型调用计数始终为 0。

macOS 最终应用实际打开，首页没有自动公告或初始化弹窗，环境就绪；包内为脚本 0.1.1。此前的正常浏览器退出经过软件自身确认和保存流程。

这些是限定配置下的冒烟检查，不代表所有课程平台、模型或用户已有环境都已验证。

## 分包检查

发行清单记录发布源码提交、两端目标架构、桌面和脚本版本，以及每个下载文件的 SHA-256。Windows 分包检查安装器版本及源码提交；macOS 分包检查包内脚本、运行时架构、许可证和签名完整性。
